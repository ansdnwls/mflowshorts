# mflowshorts

해외 바이럴 영상의 출처 후보를 찾고, 아침 10분 동안 검토하기 위한 초기 개발 버전입니다.

## 실행

Python 3.11 이상 (미디어 도구 고정 버전이 3.11 이상 필요). 기본 YouTube 앱은 표준 라이브러리로 실행합니다. Douyin·TikTok 연동은 아래 미디어 도구 설치 절차가 필요합니다.

```bash
cd /workspace/mflowshorts
python3 app.py
```

### Windows 설치

프로젝트 폴더(예: `F:\프로젝트\mflowshorts`)의 cmd 또는 PowerShell에서 실행합니다.

```bat
scripts\install_windows.cmd -CheckOnly   :: 설치 없이 상태만 확인
scripts\install_windows.cmd              :: 없는 항목 설치 후 다시 확인
python app.py                          :: 기본 포트 8020 (http://127.0.0.1:8020)
```

스크립트는 Python 3.11+ (없으면 3.12 설치), Git, FFmpeg·ffprobe, 맑은 고딕 Bold(`C:\Windows\Fonts\malgunbd.ttf`), 미디어 가상환경(`data\media-venv`, `requirements-media.lock` 고정 버전), douyin-downloader 고정 커밋, Playwright Chromium을 확인합니다. 없는 프로그램은 winget으로 설치하고, 마지막에 앱과 같은 ASS 자막·글꼴로 한글 제목 영상을 실제로 만들어 봅니다. 기존 `data\` 내용은 지우거나 덮어쓰지 않습니다. `-SkipMedia`를 붙이면 Douyin·TikTok 도구 설치를 건너뜁니다. 새로 설치한 프로그램이 있으면 새 터미널 창에서 앱을 실행하세요. Windows의 TikTok 검색은 `CHROMIUM_PATH`가 없으면 Playwright가 내려받은 Chromium을 사용합니다.

#### AI 자막 지우기 (NVIDIA 그래픽카드, 선택)

```bat
scripts\install_ai_eraser.cmd -CheckOnly   :: 그래픽카드와 설치 상태만 확인
scripts\install_ai_eraser.cmd              :: 그래픽카드에 맞는 패키지를 내려받아 설치
```

원본 글자 가리기의 "AI 자막 지우기 (NVIDIA)" 모드는 [video-subtitle-remover](https://github.com/YaoFANGUK/video-subtitle-remover)(Apache-2.0)의 Windows 실행 패키지를 씁니다. 스크립트는 `nvidia-smi`로 그래픽카드 세대와 드라이버 버전을 읽어 CUDA 11.8 / 12.6 / 12.8 패키지 중 하나를 고릅니다. 패키지에는 Python·PyTorch·PaddleOCR이 들어 있어 용량이 수 GB이고, PC의 Python은 건드리지 않습니다. 이 도구의 문자 인식은 한글 경로의 모델 파일을 읽지 못하기 때문에, 프로젝트 경로에 한글이 있으면 `%LOCALAPPDATA%\mflowshorts\vsr`에 설치합니다. 설치 위치는 `data\vsr-path.txt`에 적힙니다. 자동으로 받을 수 없으면 릴리스 페이지에서 직접 받은 뒤 `-Archive 파일경로`로 설치하세요. 렌더할 때는 박스 안에서 자막이 보이는 프레임만 찾아(OCR) STTN으로 다시 그립니다. 처리 기록은 렌더 폴더의 `ai_eraser.log`에 남습니다.

로컬 포트 기본값은 8020이며 `PORT`로 변경할 수 있습니다. 서버는 기본적으로 루프백에만 바인딩합니다. 사용자 인증이 없는 개인 개발용입니다.

## 가능한 작업

- 영어·중국어 검색어별 YouTube, TikTok, Douyin, Instagram 검색 진입
- 4개 플랫폼의 HTTPS 출처 후보 링크 저장
- YouTube Data API v3 키가 있으면 최근 1~14일, 검색어 최대 5개의 짧은 영상 후보 자동 수집
- 조회수, 좋아요, 댓글, 참여율, 게시 후 일평균 조회수 비교
- 1시간 이상 간격 재수집 이후 시간당 관측 조회수 증가량 표시
- 각 영상에서 동일 제목 검색·유사 업로드 비교로 원본 조사
- 선택적으로 매일 한국 시각 지정 시간 수집 (기본 꺼짐)

## YouTube 연결

Google Cloud 프로젝트에서 YouTube Data API v3를 활성화한 API 키가 필요합니다. 키는 `YOUTUBE_API_KEY` 런타임 환경변수로 안전하게 주입하세요. 소스, 채팅, Git에는 넣지 마세요. 이 앱은 키를 브라우저로 보내지 않습니다. 아웃바운드 HTTPS에 `www.googleapis.com`이 허용되어야 합니다. 실제 키로 한국어·영어·중국어 검색과 채널 통계 조회를 검증했습니다.

검색어 5개를 모두 사용하면 한 번 수집에 search.list 5회 및 videos.list 최대 3회를 호출합니다. 검색 할당량은 특히 제한적이므로 짧은 간격으로 반복 수집하지 마세요. 검색 결과는 키워드당 최대 25개이며 전체 플랫폼을 망라하지 않습니다. `videoDuration=short`는 4분 미만 영상으로 Shorts 전용 검색이 아닙니다.

## 한계와 출처 검토

Instagram은 검색 이동·수동 링크 저장 단계이며 Google 검색을 이용합니다. Douyin·TikTok은 수집·다운로드 작업을 연결했으나, 현재 실제 플랫폼 접속은 클라우드 네트워크 정책에 막혀 있습니다. 아래 검증 상태를 확인하세요.

게시물 링크는 원저작자를 보증하지 않습니다. 동일 장면의 이전 게시물, 작성자 프로필, 워터마크와 설명 등을 비교하고 사용 허가를 확인해야 합니다. 원본 자동 판별·재게시 기능은 없습니다. 영상 다운로드 작업의 구현과 실제 성공 검증은 구분합니다. 비공개 통계는 0으로 채우지 않으며 공유 수는 YouTube API에서 제공되지 않습니다. 참여율은 동일 분야 대비 이상치 판정이 아닌 단순 비교 지표이고, 일평균 조회수는 급상승 증거가 아닙니다.

자동 수집은 서버 프로세스가 켜져 있어야 실행됩니다. 지정 시간이 지난 후 시작하면 당일 수집을 시도합니다. 하루 한 번 시도하고 실패는 기록에 표시되며, 수동 재시도할 수 있습니다. 종료 중 놓친 날짜를 소급 수집하지 않습니다.

SQLite 데이터는 무시 경로 `data/mflow.db`에 보관합니다. `MFLOW_DB`로 위치를 바꿀 수 있습니다. 기존 프로젝트 체크아웃을 사용하고 별도 worktree를 만들 필요가 없습니다.

```bash
python3 -m unittest discover -s tests -v
node --check web/app.js
```

단위 테스트의 YouTube 응답은 모의 데이터이며 실제 API 검증을 대신하지 않습니다.

## 발굴 대시보드

검색 지역·검색어·기간·최소 조회수를 지정한 뒤 **조건으로 발굴**을 누르면 입력 조건을 저장하고 실제 YouTube 검색을 실행합니다. 지역은 API의 시청 가능 지역이며 제작 국가가 아닙니다. 검색어 언어도 영상 언어를 보장하지 않습니다.

- 참여율·조회수·최신·실제 관측 증가량 순 정렬, 제목·채널 내 검색, 조회수 필터
- 카드·목록 전환, 별표 저장함 (발굴 기간이 지나도 저장한 영상 유지)
- 원본 추적 노트: 설명글의 @아이디 후보 표시, 출처 링크·단서·확인 상태·새 해석 메모
- 채널 성과 분석: 카드에서 요청하면 공개 업로드 목록 최대 50개의 조회수 중앙값 계산. 표본 수·구독자 수·분석 시각을 저장하고 6시간 재사용. Shorts·롱폼이 혼합된 표본이며 영상 연령 보정은 하지 않습니다. 중앙값이 0이거나 비공개 수치는 비율을 산출하지 않습니다.
- 채널 중앙값 대비 1.5/2/3/5배 필터, 구독자 상한 필터. 분석한 채널만 대상이며 미분석·구독자 비공개 채널은 필터 적용 시 제외됩니다.
- UTF-8 BOM CSV 내보내기: 현재 화면 필터와 관계없이 수집한 모든 영상·추적 메모를 내보냅니다. 스프레드시트 수식 해석을 막기 위해 위험 접두어를 이스케이프합니다.

`누적 시간평균`은 조회수 ÷ 게시 후 경과시간이며 실제 최근 상승 속도가 아닙니다. `관측 증가량`은 재수집 사이의 조회수 차이 ÷ 시간 차이입니다. 1시간 이상 간격의 관측이 필요합니다.

썸네일은 `i.ytimg.com` HTTPS 접근이 필요하며 실패 시 대체 화면을 표시합니다. 화면은 데스크톱과 390px 모바일에서 검증했습니다. 실제 한국어·영어·중국어 검색 및 50개 업로드 채널 분석을 현재 환경의 API 키로 확인했습니다.

AI 생성, 자동 원본 인증, Lens 자동 실행, 자동 게시 기능은 포함하지 않습니다. 외부 영상 다운로드 작업은 아래 별도 연동을 사용합니다.

브라우저 회귀 검증은 `python3 scripts/browser_smoke.py`로 실행할 수 있습니다. 선택 개발 도구인 Python Playwright와 Chromium이 필요하며, `CHROMIUM_PATH`로 브라우저 경로를 지정합니다. 임시 DB와 포트 8001을 사용하고 실제 사용자 데이터는 변경하지 않습니다.

## Douyin · TikTok 수집 및 다운로드

미디어 도구는 별도 가상환경에 설치합니다. 기존 파일과 데이터는 유지하며 외부 도구의 소스 수정 없이 연결합니다.

```bash
bash scripts/install_media.sh
python3 app.py
```

`해외 소스 탐색`에서 플랫폼과 작업을 고릅니다.

- **Douyin 검색**: 최근 7일·좋아요순 한 페이지 최대 10개
- **Douyin 인기 목록**: 영상 순위가 아닌 인기 검색어 최대 20개. 검색어를 눌러 추가 발굴
- **TikTok 검색**: 정상 Chromium 브라우저의 공개 검색 응답 읽기, 최대 10개. 로그인 또는 화면 변경으로 실패할 수 있음
- **링크 정보**: 개별 영상 또는 공식 짧은 공유 링크에서 공개 메타데이터 가져오기
- **다운로드**: yt-dlp로 영상 파일 저장. 완료 파일만 다운로드 버튼 표시. 최대 200MB, 작업 최대 4분, 동시에 최대 2개

작업 상태는 DB에 기록하고 화면에서 갱신합니다. 빈 응답은 성공으로 위장하지 않습니다. 서버 재시작으로 중단된 작업은 오류 처리하며 재시작 후 직접 재시도할 수 있습니다. 외부 영상은 조회수가 공개되지 않아도 `수집한 외부 영상`에 표시됩니다. 원본 추적 노트에서 제작 후보로 저장할 수 있습니다. 채널 중앙값 분석은 YouTube 전용입니다.

### 검증 상태와 필요한 설정

도구 설치·반복 설치, 정규화·메타데이터 저장·오류 상태·부분 파일 정리 테스트는 통과했습니다. 실제 Douyin 검색·인기 목록과 사용자가 제공한 TikTok 링크의 정보·다운로드 요청은 **클라우드 프록시의 정책 차단**을 확인했습니다. 플랫폼까지 도달하지 못했으므로 실제 외부 검색·다운로드 성공을 검증한 상태는 아닙니다.

현재 필요한 HTTPS 허용 호스트: `www.douyin.com`, `v.douyin.com`, `www.tiktok.com`, `vm.tiktok.com`, `vt.tiktok.com`. 정책 적용 이후 반환되는 영상 CDN 호스트도 필요할 수 있으며, 실제 요청에서 확인 후 추가해야 합니다. 승인되지 않은 프록시 우회나 TLS 검증 비활성화는 하지 않습니다.

로그인이 실제로 필요한 경우 본인 계정의 Netscape 형식 쿠키 파일을 보안 경로에 두고 `DOUYIN_COOKIE_FILE` 또는 `TIKTOK_COOKIE_FILE`에 경로만 지정할 수 있습니다. 값·파일 내용은 채팅·Git에 공유하지 마세요. 현재 실패는 로그인 문제가 입증된 것이 아니므로 쿠키는 먼저 요구하지 않습니다. 사람 확인과 플랫폼 접근 제한은 자동 우회하지 않습니다.

도구: `yt-dlp 2026.10.26`, `jiji262/douyin-downloader` 커밋 `1e08f03b8909b364fb6237d8f9f441e3fbf3d427`. API·플랫폼 변경에 따라 유지보수가 필요합니다. TikTok 검색은 Playwright와 시스템 Chromium을 사용하며 `CHROMIUM_PATH`로 경로를 지정할 수 있습니다. 패키지 버전은 `requirements-media.lock`에 고정됩니다. 영상 다운로드 결과는 원작자 확인이나 재사용 허가를 보증하지 않습니다.

제작 기능 참고 화면의 분석과 후속 흐름은 [docs/production-reference.md](docs/production-reference.md)에 정리했습니다. AI 제작·자동 게시 기능은 없습니다. 수동 대본 기반 로컬 렌더링은 아래 절차로 사용할 수 있습니다.

## 로컬 쇼츠 제작

외부 플랫폼 접속 없이 본인이 준비한 원본 파일로 제작할 수 있습니다.

1. **채널 설정**에서 제작 채널을 등록합니다. YouTube 계정 연결이나 게시 권한을 부여하는 기능이 아닙니다.
2. **프로젝트 관리 → 새 프로젝트**에서 제목과 채널을 선택합니다. 또는 발굴 영상의 원본 추적 노트에서 **제작 프로젝트로 이어가기**를 누르면 출처 링크와 추적 메모를 가져옵니다.
3. MP4/MOV/WebM 원본을 업로드합니다. 최대 200MB·90분·8K 이하이며 서버에서 실제 영상 스트림을 검사합니다.
4. 기본/깔끔/강렬 빨강/뉴스형 스타일, 시작 지점, 1~60초 길이, 자막·원음·좌우반전을 선택합니다. 스타일을 채널 템플릿으로 저장해 다음 프로젝트에 재사용할 수 있습니다.
   상단 제목은 두 줄로 크게 나오며 첫 줄과 둘째 줄이 스타일별로 다른 색입니다. 대본에서 `*강조할 단어*`처럼 별표로 감싼 부분은 자막에서 강조 색으로 표시됩니다. 제목·자막은 ASS 자막으로 그립니다. 기본 글꼴은 `MFLOW_FONT`(기본: 맑은 고딕 Bold)이며, `fonts` 폴더에 넣은 .ttf/.otf 글꼴을 프로젝트마다 **제목 글씨체·자막 글씨체**로 따로 고를 수 있습니다(`fonts/README.md` 참고).
   영상 배치는 **위아래 검정**(기본: 위 검정에 제목, 가운데 영상, 아래 검정에 댓글), **화면 꽉 채우기**(제목 아래를 끝까지 영상으로), **원본 맞추기**(자르지 않고 가운데, 빈 곳은 검정) 중에서 고릅니다. 어느 쪽이든 상단 제목이 영상을 가리지 않습니다.
   선택 사항으로 제목 아래 작은 **출처 표시** 한 줄과, 정한 시점부터 나오는 한국어 **댓글 카드**(닉네임·시간·댓글, 최대 3개)를 넣을 수 있습니다. 댓글은 직접 입력하며 자동 수집·번역은 하지 않습니다.
5. 상단 문구와 직접 작성한 대본을 저장하고 **대본·설정 승인**을 누릅니다. 원본·제목·대본·설정이 바뀌면 승인이 해제됩니다.
6. **렌더링 시작**으로 로컬 FFmpeg 제작을 실행합니다. 승인한 버전의 해시를 결과에 기록합니다. 동시에 한 프로젝트만 렌더링하며 제한 시간은 8분입니다.
7. 완성된 **1080×1920 MP4**와 **자막·프로젝트 ZIP**을 내려받습니다. ZIP은 MP4·SRT·JSON 설정이며 CapCut 전용 프로젝트가 아닙니다.

직접 쓴 대본만 쓰는 경우 원음을 유지하거나 무음으로 만들고, 대본 자막은 영상 길이에 균등 배치(또는 자막 타임라인)합니다. 실제 발화 타이밍을 자동 인식하지 않습니다.

### 분석 → 대본 → 나레이션 → 편집 → QA

1. **장면·음성 분석 검토**: **분석 양식 만들기**는 빈 양식(장면 1개)을 만듭니다. 영상을 자동으로 보고 듣는 기능이 아닙니다. 원본을 보며 장면별 시작·끝 시간, 화면 설명, 대사, 화면 자막·아이디 단서를 적고, **확인된 사실**과 **추정**(의도·원인·출처)을 따로 적습니다. **분석 확정**을 눌러야 다음 단계로 갑니다. 분석을 고치면 확정·대본·나레이션·승인이 모두 풀립니다.
2. **대본 생성**: 확정한 분석의 사실만으로 훅 → 상황 → 마무리 문장을 만듭니다. 사실 문장과 추정 문장이 표시되며, 추정은 항상 "추정으로는 … 확인되지 않았습니다" 형태로 나옵니다. 현재는 정해진 문장 틀을 쓰는 모의 생성기이며, 대본을 손으로 바꾸면 승인이 거부됩니다(분석을 고쳐서 다시 생성).
3. **대본·설정 승인** 후 **나레이션 생성**: 문장마다 WAV를 만들고 실제 파일 길이로 문장 시간을 잽니다. 기본(`MFLOW_TTS_ENGINE=mock`)은 **무음** 시험 파일입니다. Windows에 설치된 한국어 음성으로 읽으려면 `set MFLOW_TTS_ENGINE=sapi` 후 서버를 켭니다. 외부 API는 부르지 않습니다. 최대 60초.
4. **렌더링**: 문장마다 연결된 장면을 원본에서 잘라 붙입니다. 장면이 문장보다 짧으면 마지막 화면을 멈춰 두고, 같은 장면을 여러 문장이 쓰면 이어지는 부분을 씁니다. 자막은 문장별 실측 시간 안에서 나눠 표시하고, 원음은 나레이션 동안 18%로 줄여(덕킹) 섞습니다. 글자 지우기·블러 박스도 함께 적용됩니다. 이때 시작·길이 설정 대신 분석 장면 시간이 쓰입니다.
5. **QA 점검**: 문장·장면 연결, 자막 시간 겹침·범위, 자막 줄 넘침(글자 수 기준 추정), 오디오 클리핑과 길이를 검사합니다. 렌더링 후에는 최종 믹스 소리로 다시 검사해 ZIP에 `qa-report.json`으로 넣습니다. 화면과 대본의 의미가 맞는지는 사람이 확인해야 합니다. 명령줄: `python scripts/qa_check.py --analysis analysis.json --script script.json --narration narration.json --audio mix.wav`. 프로젝트의 언어 선택은 메모이며 번역·합성 음성 실행이 아닙니다.

프로젝트 카드의 진행률은 제작 단계 기준이며 인코딩 프레임 진행률이 아닙니다. 렌더링 중에는 편집을 막습니다. 서버 재시작으로 중단된 렌더는 오류 상태가 되어 다시 시도할 수 있습니다. 원본과 버전별 결과는 `data/projects/`에 보존하며 자동 삭제하지 않습니다. `MFLOW_PROJECT_ROOT`로 위치를 지정할 수 있습니다. 로컬 단일 사용자 용도이며 공개 서버 배포·계정 인증·자동 게시 기능은 없습니다.

필수 시스템 도구: `ffmpeg`, `ffprobe`, `/usr/share/fonts/opentype/noto/NotoSansCJK-Bold.ttc`. 현재 클라우드에는 이미 설치되어 있으며 실제 렌더링으로 검증했습니다.

글꼴은 Linux Noto CJK, Windows 맑은 고딕 Bold(`C:/Windows/Fonts/malgunbd.ttf`), macOS Apple SD 고딕 순서로 찾습니다. 다른 글꼴은 `MFLOW_FONT`에 경로를 지정하세요. 맑은 고딕은 중국어 간체 일부 글자를 표시하지 못할 수 있습니다. 업로드 원본은 MP4/MOV/WebM 계열 형식만 받으며 재생목록(HLS 등) 파일은 거부합니다.

서버는 `Host`가 `127.0.0.1`·`localhost`인 요청만 처리합니다. 다른 주소로 접속하면 403이 반환됩니다.

```bash
python3 -m unittest discover -s tests -v
node --check web/app.js
node --check web/production.js
python3 scripts/production_smoke.py
```

제작 브라우저 테스트는 임시 DB·프로젝트 디렉터리·포트 8002와 생성한 테스트 영상을 사용합니다. 실제 업로드·FFmpeg 렌더·원음·1080×1920 결과·승인 해제·템플릿·ZIP·HTTP Range·새로고침 유지·모바일을 검증하며 사용자 프로젝트를 변경하지 않습니다.
