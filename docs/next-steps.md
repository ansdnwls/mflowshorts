| 단계 | 진행 현황 |
| --- | --- |
| 장면·음성 분석 | 프레임과 음성 추출, 수동 검토, 선택형 OpenAI 분석, 사실·추정 분리 및 확정 |
| 대본 | 확정된 분석으로 로컬 대본 또는 OpenAI 근거 선택, 문장별 장면·사실·추정 표시 |

| 소재 발굴 | 성과 기준 수집, 사용 근거와 원본 후보 링크 저장, 제작 프로젝트·성과 연결 |

## 다음 검증

- API 키를 서버 환경에 설정한 뒤 실제 영상 한 편의 프레임, 원음 전사, 확정 대본, 음성 품질을 확인합니다.
- 영상 시각 유사도로 중복 원본 후보를 찾고, 수동으로 기록하는 게시 성과를 자동 수집할 수 있는지 검증합니다.
- 실제 게시 계정 설정 후 테스트용 프로젝트의 게시 예약과 재시도 동작을 검증합니다.
