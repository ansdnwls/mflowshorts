# 제작 단계 참고: 사용자가 제공한 ReelBox 화면

2026-11-04 제공된 화면 기준. 사이트 내부 실행을 재현하거나 생성물 품질을 검증한 자료는 아니다. 현재 앱에서 아래 제작 기능을 구현했다고 해석하지 않는다.

## 후속 제작 흐름

1. 프로젝트: 채널·상태·포맷 필터, 제목 검색, 진행률, 검수 상태, 작업 계속
2. 원본 업로드: 새로 제작 / 완성 쇼츠 언어 변환을 구분. 채널·제작 언어 선택
3. 스타일 선택: 기본, 깔끔 자막, 강렬 빨강, 손글씨, 뉴스형 등의 프리셋과 세부 미리보기
4. 스타일 설정: 언어, 화면 틀, 상단 문구, 자막, 댓글 카드, 강조효과, 내레이션, 효과음·배경음악, 이야기 틀, 직접 대본, 처리 방식, 마무리
5. 채널 템플릿으로 설정을 저장하거나 이번 제작에만 적용
6. 대본 생성 후 **사용자 확인 대기**. 대본·상단 제목 등을 수정하고 명시적으로 진행
7. 렌더링·검수 작업과 오류/재시도 상태
8. MP4 다운로드, 편집 프로젝트 내보내기, 타임라인 편집

우리 프로그램에서는 수집한 출처 후보·원본 확인 상태·사용자가 확인한 실제 맥락과 새 해석 메모를 제작 프로젝트에 넘기는 구조가 적합하다. 표면적인 스타일 복제에 앞서 원본과 편집 산출물, 대본 승인 버전을 구분해 보존한다.

## 참고할 UI 세부 사항

- 좌측 주요 메뉴와 채널 설정, 프로젝트 카드의 단계·검수 상태
- 영상 미리보기와 설정 패널을 나란히 배치
- 내레이션·화면 속 원음 자막을 별도 제어
- 길이, 속도, 품질, 검수 횟수 설정
- 제작 진행 전 예상 비용·작업 범위 표시 (우리 시스템의 실제 요금 체계는 미정)
- 언어 변환과 좌우반전 설정은 별도 기능. 반전 자체로 새로운 저작물이 되거나 출처가 확인되는 것은 아님

## 현재 작업과의 구분

현재는 YouTube 발굴·성과 비교·저장·출처 노트, Douyin/TikTok 수집 도구 연결에 더해 채널 템플릿·제작 프로젝트·원본 업로드·수동 대본 승인·FFmpeg MP4 렌더·SRT/JSON ZIP 출력을 구현했다. 실제 테스트 영상과 브라우저로 검증했다. AI 대본, TTS, 자동 번역, CapCut 전용 프로젝트 출력은 미구현이다. 영상 내용 자동 분석과 합성 음성에는 별도의 모델·음성 제공자 및 검증이 필요하다.
